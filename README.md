# Expense Tracker

A simple expense tracker built with HTML, CSS and JavaScript.

## Features
- Add income and expense entries with a category
- See your balance, total income and total expenses
- Delete entries
- Data is saved in the browser with `localStorage`

## How to Run
1. Save the code as `index.html`
2. Double-click the file to open it in your browser

No installation needed.

## How to Use
1. Enter a description and an amount
2. Choose Income or Expense, then pick a category
3. Click **Add**
4. Click **x** next to an entry to delete it

## Technologies
- HTML
- CSS
- JavaScript (`localStorage`)
